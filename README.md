## Возможности

- Переименование файлов на основе даты съёмки

### Поддерживаемые типы файлов

- AVIF, BMP, DNG, EPS, GIF, HEIF/HEIC, ICO, JPEG/JFIF, Netpbm, PCX, PNG, PSD, TGA, TIFF/BigTIFF, WebP
- 3FR (Hasselblad), ARW (Sony), CRW/CR2/CR3/CRX (Canon), GPR (GoPro), KDC (Kodak), NEF (Nikon), ORF (Olympus), PEF (Pentax), RAF (Fujifilm), RW2 (Panasonic), RWL (Leica), SRW (Samsung)
